🎬 SAMFLIX
SAMFLIX is a high-performance, beautiful media streaming application built specifically for BDIX server networks. Powered by Flutter and the native libmpv engine via media_kit, it delivers a professional-grade cinematic experience directly on your Android device.

✨ Key Features
🚀 High-Performance Native Playback: Bypasses standard software players. Uses media_kit (C++ libmpv) to decode and play complex multi-channel audio and HEVC formats flawlessly.

📱 Immersive Cinematic UI: True edge-to-edge fullscreen playback. Safely bypasses Android system navigation bars for an uninterrupted viewing experience.

🔍 Deep Universal Search: Instantly scan BDIX directories with persistent, local search history so you never lose track of your favorite shows.

📥 Background Downloading: Full integration with flutter_downloader. Queue up massive 1080p files, send the app to the background, and track live MB/s speeds.

🎬 TMDB Metadata Integration: Automatically fetches high-quality backdrops, cast lists, and official movie overviews based on raw BDIX file names.

🛡️ Smart Path Resolution: Intelligently bypasses Android 11+ Scoped Storage restrictions for reliable file management.

🛠️ Tech Stack
Framework: Flutter (Dart)

Media Engine: media_kit (libmpv)

Storage & History: shared_preferences

Download Manager: flutter_downloader

Metadata API: TMDB (The Movie Database)
